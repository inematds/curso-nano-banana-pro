Escribir prompts clarosConvierte tu intención en decisiones de luz, forma y composición.

Cómo estudiar

Lee una lección y reserva diez minutos para la práctica. Tu progreso queda en este navegador. Exporta tu recorrido para guardar una copia.

Las imágenes son ilustraciones generadas en Codex. Para las prácticas de generación necesitas acceso a un servicio de imágenes y quizá créditos. El curso orienta sobre Gemini y pide registrar el modelo que realmente usaste. Las ilustraciones de Codex no son resultados de Nano Banana.

Para quién es

Es para ti si

  • Creas imágenes para una tienda o un negocio artesanal y quieres mostrar los productos con claridad.
  • Ya usas un chat de imágenes y tienes poco tiempo en cada sesión.
  • Prefieres aprender haciendo.

No es para ti si

  • Ya dominas el tema y buscas algo técnico.
  • Quieres una videoclase tradicional.
