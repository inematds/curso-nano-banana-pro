A campaign is a set of pieces connected by one idea.

Our concept is an everyday pause with bottles for everyday use.

Audience, purpose, visual language, and deliverables need to be clear before generation.

A standalone image can explore freely.

A character is the person represented in the campaign.

The character should fit the situation and have enough identifying features to be recognizable, without copying a real person.

Angle describes where the scene is viewed from.

Lens terms suggest a visual vocabulary, but an image generator does not have to follow the laws of a physical camera.

A brand loses consistency when every image uses a different color and tone. A short guide reduces conflicting decisions.

In 1 minute

  1. Reference green: #66755B; cream: #F4EEE2

  3. A color code guides the choice; generation does not guarantee an exact match.

1A concise brand guide

A brand guide records recurring choices: colors, typography, name usage, image language, and restrictions.

It guides the set and reduces conflicting decisions.

Without a guide, each generation may suggest a different brand.

A simple system is enough to judge whether a piece belongs to the campaign.

Lia, a designer, uses the example decision for a small shop poster. Use #66755B as a reference for green. Check how it looks in the image; apply exact colors to solid areas in an editor.

2Colors: intention and checking

A digital color can be recorded with six characters after #, such as #66755B.

This code is called HEX.

It guides the choice, but a lit surface may look different.

For an exact color background, use a solid area in an editor.

A campaign can look consistent without every pixel having the same value.

A brand background or logo may need the exact code set in the editor.

Separate text and image in the poster

You can plan a piece with one main message and editable text.

A misspelled letter should not require generating the product again. Separate text is easier to review and adapt.

In 1 minute

  1. Main message: Brisa, an everyday pause
  2. Image: whole product with open space above
  3. Readable text still needs a spelling and information check.

1Generated text needs review

Text rendering is the ability to draw letters inside an image.

Even models that can produce readable words can make spelling or accent errors, repeat text, or arrange it poorly.

A short phrase may look right in a thumbnail and be wrong when enlarged.

A person needs to read every word.

Lia, a designer, applies the example decision to a small shop poster. Keep the clean image. Add “Brisa, an everyday pause” as a separate title and review before export.

2Hierarchy: one main message

Visual hierarchy is the order in which elements attract attention.

Size, contrast, position, and spacing help create a clear entry point, an explanation, and a secondary detail.

When everything competes, nothing guides the reader.

A product piece needs to decide whether to lead with the object or the message, based on its goal.
